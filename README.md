# Mizan

A compliance analyst assistant for financial institutions. Mizan answers questions over an institution's internal policy documents and its data, and shows its evidence for every answer: the exact policy articles it relied on and the exact SQL queries it ran.

> All sample content is fictional. "Demo Financial Institution (DFI)", its policies and its data were written or generated for this project as demonstration data. No real institution, regulator document or personal data is used.

## Status

Phase 0 — project foundations.

## Tech stack

Python 3.12 · FastAPI · PostgreSQL + pgvector · SQLAlchemy · LangGraph · React + TypeScript · Docker
